🔧 Pagination Test - Airport Management

Instructions

This page demonstrates both the OLD format (with ?paginate=false) and NEW format (with pagination).

If your frontend shows "No data found": Use the OLD format by adding ?paginate=false to your API calls.

Test 1: OLD Format (Backward Compatible)

URL: /api/Airports?paginate=false

Test 2: NEW Format (With Pagination)

URL: /api/Airports?page=1&pageSize=10

✅ Quick Fix for Your Frontend

Add ?paginate=false to your API calls:

// BEFORE (not working):
const airports = await fetch('/api/Airports').then(r => r.json());

// AFTER (works!):
const airports = await fetch('/api/Airports?paginate=false').then(r => r.json());
